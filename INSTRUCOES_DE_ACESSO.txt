  Link de acesso: https://brasil-overview.onrender.com/

* Observação: Por estar hospedada no plano gratuito do Render,
  se o servidor estiver em repouso após inatividade, a primeira
  abertura pode demorar cerca de 30 a 50 segundos para subir.
  Depois de carregada, a navegação é imediata.

------------------------------------------------------------
2. EXECUÇÃO LOCAL (OPCIONAL)
------------------------------------------------------------
Caso queira executar a aplicação no seu ambiente local:

Pré-requisito: Ter o Node.js (v18 ou superior) instalado.

Passo a passo no terminal:
1. Abra a pasta do projeto:
   cd Brasil_overview

2. Instale as dependências:
   npm install

3. Inicie o servidor local:
   npm run dev

4. Abra no navegador o endereço informado (geralmente):
   http://localhost:5173
